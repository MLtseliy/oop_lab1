## oop_lab1

## Описание
Класс Book с инкапсуляцией: приватные поля, геттеры и сеттеры с валидацией,
метод getDescription(). В Main создаются три объекта и выводится список книг.

## Структура
- src/main/java/com/university/lab01/model/Book.java — класс книги
- src/main/java/com/university/lab01/Main.java — точка входа
- docs/prompts/ — журнал применения ИИ

## Запуск
Java 17+, Maven. Запустить класс Main из IntelliJ IDEA.
